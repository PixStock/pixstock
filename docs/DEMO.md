# Reproduire la démo

> **À rédiger (J4-J5).** Source : `PLAN_INTEGRATION.md §16.1`.

## Mode « canal collé » (sans caméra)

Pour les tests automatisés et l'accessibilité, le vault accepte les trames
par collage. C'est le mode utilisé par les tests Playwright de bout en bout,
et celui qu'un juge sans second appareil peut utiliser.
